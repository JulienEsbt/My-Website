# On-chain archiving portfolio illustration

Original vector illustration created for the portfolio on 26 October 2026. It replaces the IDE screenshot for the academic Megalis project. No third-party image or generated product screenshot is used.

The document → smart contract → blockchain diagram represents publication of a document URL, a caller-supplied SIREN and the block timestamp, as described in [Megalis-Smart-Contract](https://github.com/JulienEsbt/Megalis-Smart-Contract/blob/master/README.md) (README blob `51ad359eb9970053f0b58ced0f4e7a0725dec1b6`). The diagram represents document references; it does not imply that file bytes are stored on-chain or that the publisher's identity is verified.

The SVG is imported from `src/assets/images/projects/onchain/document-timestamp.svg`, so Vite includes a versioned local URL in local, preview and production builds. Vector rendering remains sharp without multiple raster exports. The image has French and English alternative text; its short diagram labels are shared technical terms.
