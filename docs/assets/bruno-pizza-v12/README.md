# Captures Bruno Pizza v1.2

Originaux fournis par Julien le 2 octobre 2026, conservés sans modification. Ordre de la galerie : tableau initial, édition, totaux corrigés, catalogue pizzas, ingrédients, distributeurs, montage initial, montage intermédiaire, résultat final, fin du parcours.

Les variantes WebP (640, 1280, 2048 et 3420 px) sont servies par Vite, sans dépendre du stockage distant. Les originaux ne sont pas chargés par la page.

Pour régénérer les variantes depuis ces originaux : `node scripts/generate-bruno-gallery.mjs`.
